life-butler 隐私说明

最后更新：2026-10-19

life-butler 是作者自己使用的自托管程序，只访问作者本人授权的 Google 账号。

  • 读取：通过 Google Calendar API 只读读取日历列表和日历事件（calendar.calendarlist.readonly、calendar.events.readonly），用来安排计划。
  • 写入：只在它自己创建的「管家」日历里创建、修改和删除事件（calendar.app.created），不修改其他任何日历。
  • 存储：数据只保存在作者自己的电脑上。
  • 共享：作者在自己的 ChatGPT 对话里请求规划时，程序会把相关日程交给这个对话使用；除此之外不分享给任何第三方，不出售，不用于广告，也不用于训练通用 AI 模型（程序只在作者自己的电脑上做个性化的时长估计）。
  • 撤销：随时可以在 Google 账号的「第三方应用和服务」中撤销授权；撤销后程序无法再访问日历。

life-butler 对从 Google API 获得的信息的使用和传输，遵守 Google API 服务用户数据政策，包括其中的有限使用要求。

Privacy Policy (English)

Last updated: 2026-10-19

life-butler is a self-hosted program used only by its author. It accesses only the Google account that its author authorizes.

  • Reads: the calendar list and calendar events, read-only, through the Google Calendar API (calendar.calendarlist.readonly, calendar.events.readonly), to plan the day.
  • Writes: only events in the secondary calendar that it creates itself, named "管家" (calendar.app.created). It never changes any other calendar.
  • Storage: data stays on the author's own computer.
  • Sharing: when the author asks for planning in the author's own ChatGPT conversation, the program passes the relevant schedule to that conversation. Apart from that, data is not shared with any third party, not sold, not used for advertising, and not used to train generalized AI models (the program only fits small personal duration estimates on the author's own computer).
  • Revoking: access can be revoked at any time under "Third-party apps & services" in the Google Account. After that the program can no longer access the calendar.

life-butler's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
